# Working on Prompt or Tune

This is a curated portfolio export of a completed experiment. Preserve the
recorded inputs, expected labels, predictions, and negative results.

Before a behavior change, state the hypothesis and expected metric effect,
write a failing regression test, and run `uv run --locked pytest -q` after the
change. Do not put evaluation examples in SFT training or compare unmatched
models, prompts, or inputs as a controlled effect.

The public CLI is offline. Do not train, infer, provision resources, publish,
or change repository visibility without explicit user authorization.

Write directly and concretely. No em dashes, inflated claims, fabricated
chronology, or implied production experience.
When updating a release file, regenerate the manifest intentionally, verify the
recorded results, and document why the file changed.
