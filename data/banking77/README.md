# BANKING77 source and derived data

The CSV files in `raw/` are the unchanged PolyAI sources. The JSONL files are
this experiment's deterministic train/dev/reserve/test split and SFT export.
Run `prompt-or-tune verify` from the repository root to reconstruct and compare
them without downloading anything.

See [dataset attribution and transformations](../../THIRD_PARTY.md) and
[methodology](../../docs/methodology.md). Query text remains under CC BY 4.0.
